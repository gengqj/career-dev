# 01_sql · SQL 零基础到够用

**目标**：秋招前能独立写出金融行业最常用的查询（多表 JOIN + 分组聚合 + 窗口函数入门）。

**教材**
- 廖雪峰 SQL 教程（可在线跑）：https://liaoxuefeng.com/books/sql/
  - 3 关系模型（主键/外键/索引）→ 5 查询数据（基本/条件/排序/分页/聚合/多表/连接）→ 6 修改数据
- 牛客 SQL 快速入门题单（免费，配讲解）：https://www.nowcoder.com/exam/oj?tab=SQL篇&topicId=199
- 牛客 SQL 热题（面试题）：https://www.nowcoder.com/exam/oj?tab=SQL篇&topicId=82

**节奏**：W1–W10 每周日 1 小时，入门题单 1–30 题；11 月底前刷完基础查询，寒假做多表 JOIN。

**产出**
- `notes/` 每周 1 篇学习笔记
- 12 月前用 SQLite + `sqlalchemy`（已装）跑通"读 CSV → 建表 → 查询"的完整链路
- 春招前把 JOIN / 窗口函数补齐

**红线**：不要买《SQL面试宝典》实体套餐（79.9 元），免费题单足够。

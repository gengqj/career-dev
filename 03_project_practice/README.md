# 03_project_practice · 练手项目（寒假，1–2 月）

**目标**：在旗舰项目之前，先用 2 个小项目验证"我能独立交付一个可运行的东西"。

**候选题目**（择一或各做一个）
1. **研报数字核查器**：把 PDF 研报里的关键数字抽出来，和原始 CSV 核对，输出差异报告
   - 练：正则、PDF 文本提取、pandas 对账、异常定位
2. **A 股行业轮动看板**：用 AkShare 拉取行业/指数行情，做简单动量排序，出图
   - 练：requests/akshare 数据获取、时间序列、可视化、定时任务雏形

**硬性交付物**（每个项目都要有）
- `README.md`：背景 / 数据来源 / 方法 / 结论 / 复现方式
- `requirements.txt` 或 `environment.yml`
- 至少 3 次有意义的 git commit
- 一张能贴进简历的结果图（`assets/` 目录）

**红线**：项目是**你自己从零写的**，不得复制他人仓库代码；数据来源必须写清楚。
